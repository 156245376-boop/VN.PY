# 当前需求与阶段边界

## 目标

个人自用、在中国大陆使用 Python 研究国内期货分钟级策略，优先尽快完成可信的策略验证，
随后模拟运行，再逐步实现自动交易。初期采用天勤免费版及其支持的期货公司渠道。

多品种、多合约、长历史回测、参数研究和实验结果留存仍是后续目标。
数据覆盖、免费权限和成本按实际账户逐项验证，不以 SDK 安装成功推定全部满足。
目前没有已经确定并实现的具体进出场策略；官方示例用于理解工具和验证程序结构。

## 已完成的环境基础

1. 旧成果包含全部未提交修改，封存包可在工作区外逐文件恢复，完整性可以复核。
2. 日常入口、搜索与导入不再带入旧代码、需求和架构；原资料按需取回。
3. Python 3.13.11 与 TqSdk 3.10.2 安装在 `.venv-tqsdk`，旧环境保留原位。
4. 依赖锁定，安装与检查入口明确，环境身份、依赖一致性和工具检查通过。
5. 环境准备与离线检查不创建账户会话。

## 当前里程碑：研究与模拟闭环

- 日常入口为“启动天勤.vbs”：独立工作台窗口登录、中文目录、自选和只读主力行情；
  工作台可另开原研究窗口，提供观察/回测/显式模拟委托、停止及结果摘要。
  用户已要求记住快期账号密码：连接成功后可保存在当前用户的 Windows 凭据管理器，两窗口共用；
  下次自动显示账号，保存的密码由后台读取、不返回网页；可随时忘记，不保存到项目文件或日志。
  不记住并连接时清除原保存项；记住密码不自动连接或启动策略。
  天勤原生图形页面仅监听本机，工作台图形内嵌，研究图形仍在浏览器展示。
- “天勤现成功能”可离线查看原生组件、官方示例源码、文档与权限限制；
  官方资源留在 SDK 与技能安装目录，缺少的示例依赖随锁定环境安装，不自动运行示例。
  已安装、已接入和已通过账户验收分别标记，不把专业功能安装当作服务授权。
- 图形回测只在第二次双费回放启用；完成后停止执行、保持页面，用户结束查看后清理。
- 入口为 tools/run.ps1 的 data-check、backtest、paper；无实盘入口。
- 样本为 SHFE.rb2505、2025-03-03 至 2025-03-07，本地回测初始 10 万。
- 完成分钟 close 高于含该柱的 15 柱均线，目标多 1 手，否则 0；此为链路示例。
- 回测与模拟共享纯信号；信号依据、目标、成交、权益以 SQLite 与 CSV 留存。
- 成本使用 SDK 模型并记录来源；双倍费用使用独立回放；不能视为历史真实成本。
- paper 唯一 TqKq 主账户串行，默认观察；启用需显式 -Activate。
- 新实验整账户空仓无挂单；不自动清仓。真实主力映射改变、拒单、断线、未知操作冻结。
- 重启需显式 -Resume；只允许当日本程序干净停止且完整对账后再次启用。
  进程被杀、跨日停止或状态不完整仅能冻结核实，不自动重放；无自动换月。
- debug=False，隐藏本机凭证输入，白名单输出，结果不进 Git。
- 离线测试不等于联网验收；已核对一次主模拟账户只读连接及行情/分钟数据就绪，
  历史权限、模拟委托与持续运行仍待用户本机验证。
- 凭证输入后显示脱敏阶段进度，运行时每 15 秒显示心跳；心跳不代表行情时间已更新。

## 后续实现继续遵守的原则

- 收盘信号只使用已完成 K 线，区分行情时间、交易日和本机时钟。
- 目标持仓是意图；实际持仓、成交与未决委托需单独核实。
- 同一账户合约明确控制权，风控要约束运行中的执行任务。
- 重启、断线和状态不可信时先核实，再决定是否恢复；不得盲目重放旧目标。
- 费用、保证金、滑点和到期约束需要结合账户与真实结果核对。
- 策略、参数、输入依据和实验结果需要可追溯；模拟撮合局限必须写清。
- 凭证隔离，实盘操作在明确授权范围内执行。

个人正式策略、多品种共享资金、批量参数、样本外与实盘接入在后续阶段分别验证。
全市场永久录制、自建数据仓库、自研撮合引擎与机器学习暂缓。
封存资料不是当前需求的默认补充，不能据旧阶段规划自动扩大实现范围。

## 已确认的下一阶段产品目标（第一批实施）

用户于 2026-10-16 确认向独立桌面研究工作台推进，首页以策略、品种选择和回测验证为主：

- 中文品种目录、自选与开盘期间实时主力报价，显示主连和真实合约映射。
- 面向用户的名称以中文含义为主：品种、交割月份、交易所、周期直接说明；
  接口代码仅作为次要核对信息，不将启动文件名等开发细节作为功能名称。
  天勤内嵌图表也遵守此约定；名称未知时明确待确认，不猜测合约名称或年份。
- 连接状态统一用绿/黄/红灯与文字显示；各品种是否有有效报价单独说明，不与连接状态混为一谈。
  价格标明品种报价单位，成交/持仓标手数，时间显示北京时间的完整日期；未返回报价不显示假零值。
  放大 K 线入口仅放在图表区域，Esc 还原；中文工具栏不得换行覆盖图中价格文字。
  从外层选择品种时，内嵌图表须同步到对应的实际主力合约。口径与单位来源见 `docs/market-data-display.md`。
- 通过文字沟通实现个人策略，保留经典模板；参数支持增减改，并与可运行策略版本绑定。
- 界面选择实验、运行回测、在 K 线上定位实际成交并查看决策原因，关闭后可重新复盘。
- 复制实验并比较参数与结果；从研究版本进入快期模拟，实时记录交易与运行状态。
- 留出新闻快讯与财经日历窗口，分级并关联品种；允许配置事件前后暂停开仓等自动规则。
  金十为优先候选来源，接口权限/费用/历史范围按官方实际接入确认；暂停开仓不阻止减仓和平仓。
