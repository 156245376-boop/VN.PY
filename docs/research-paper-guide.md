# 双均线实验与快期模拟使用说明

适用：独立“天勤策略工作台”，当前分支的双均线与阶梯保护版本。
此功能已做离线计算与真实WebView2操作验收；实际账户的历史权限、真实回测及持续模拟委托仍须本机联网核对。

## 1. 打开新入口

正常退出旧窗口后，从桌面原快捷方式或项目的“启动天勤.vbs”重新打开。
已经运行的旧进程不会因代码更新而自动更换界面。

在顶部使用已保存的快期账号连接行情。密码留空会由后台读取Windows保存项，不回传到网页。
若未保存，仍在本机登录框填写；不要把密码发到聊天。
点击首页“开始策略实验”，或者左侧“策略与参数”。
“设置与资源”保留的原研究窗口用于旧固定样例，与此新实验入口不同。

## 2. 配置第一次回测

1. 策略模板选择“双均线交叉（简单均线）”，给实验起一个名称。
2. 选择中文品种、K线周期及起止交易日。快均线默认5根、慢均线20根，均可修改，快必须小于慢。
3. 默认选择“历史主力连续（自动移仓）”，无需查询月份，可以选择跨年区间。
   如需核对某个月份，切换为“固定月份合约（高级／模拟）”，再查询并选择实际合约。
4. 选择定仓方式，填写固定手数或每笔风险预算。新版不用填写止损跳数；默认用左、右各2根已完成柱确认波峰／波谷，可修改确认根数。
   最大手数和最大保证金比例是可选限制，默认关闭；仍受账户可用资金、最小手数和SDK规则约束。
5. 保留默认的1R/2R阶梯与3R终点，或者修改为自己的实验参数。
6. 按需勾选“观看交易过程（只读）”，再点“运行回测”。运行按钮会先保存一次不可变修订；修改不会覆盖以前的结果。
   固定模式未选择当前查询返回的实际合约时，运行按钮不可用；连续模式无需月份。
   保存失败会在具体输入框下显示原因，不会假装开始运行。

日期按北京时间的交易日解释，包含SDK定义的夜盘；均线预热可能使用区间前的数据，预热期间不交易。
单个月份合约不覆盖十年：已知到期日期之外的请求会被拒绝；实际回放结束后还按SDK交易日历核对中间各交易日。
查询列表会显示到期日，不能覆盖结束日的月份不可选；已知日期不匹配时，在创建回测任务前提示具体合约、日期和修改位置。
任务失败、冻结或停止后，进度条停止动画并显示结束原因；尚未收到K线时关闭空白运行图，不继续显示“等待数据”。
缺日历、数据权限或交易日覆盖时明确失败，不自动截短日期、换合约或补造数据。
末根日线没有下一根柱时，只有已核对SDK实际发送的完整CLOSE数据才能计入覆盖；记录注明“策略未消费”，回测结束后不追加开仓信号。
起步可显式选择原链路样本：螺纹钢SHFE.rb2505、2025-03-03至2025-03-07、1分钟、虚拟资金100000元。
这只是操作验收样本，不表示有效策略。账户无此段权限时会失败，不会偷偷换到另一个合约或日期。

“分钟近似（流程验证）”使用SDK分钟报价检查保护，即使信号选择小时或日线也如此。
它不能还原每分钟内部的真实价格路径。Tick模式需要实际权限与覆盖，失败不会自动降为分钟。

## 3. 手数、R与阶梯

“固定手数”：填写每次手数，止损价仍取已确认的拐点；资金不足则跳过，不静默缩小手数。
“按每笔风险预算计算手数”：用预算除以每手止损价差金额，向下取整，再核实资金、保证金、最小手数和上限。
不足最小手数会跳过开仓，不向上凑；参数或成本模型缺失也不会发单。

多单止损取最近已确认波谷，空单取最近已确认波峰。左右2/2表示：候选低点必须严格低于左2根及右2根柱的低点，
且右边第2根也已经收盘；高点相反。等高／等低不算严格拐点；没有有效拐点时等待，不偷看后面的K线。
计划价取当时多单卖一价／空单买一价，自动计算距离和手数。最近拐点在错误方向时跳过，不改用更老的拐点。
入场计划保存拐点发生、确认时间和原始止损；等待反向开仓期间，不把后来才确认的拐点套回原信号。

以下数字仅用于理解换算，不是资金或风险建议：

假设入场参考价1000、已确认波谷995、合约乘数10，则每手计划风险50元，预算1000元计划20手（还须核实资金）。
若实际均价1001，原止损仍为995，20手实际初始R为1200元；止损不会随成交均价平移，预算不保证限制实际亏损。
再举一个较大距离的例子：若拐点与参考价距离50跳、每跳1元、合约乘数10，则每手计划风险500元。
预算1000元可计划2手，实际入场2手后R为1000元；若只成交1手，则先保护实际这1手。
如果每手风险是300元，预算1000元只能开3手，实际R为900元，3R终点是2700元。

默认保护规则：

| 最高已观察毛浮盈 | 动作 |
| --- | --- |
| 未达到1R | 初始止损 |
| 达到1R | 多头保护推至开仓均价+1跳；空头为开仓均价-1跳 |
| 达到2R | 保护推至盈利0.5R的位置，按有效价格刻度取整 |
| 达到3R | 触发退出，等待实际成交确认 |

R在入场完成后固定，保护线只收紧；盈利回落不回退档位。
金额均为价差毛盈亏，手续费另列。1跳不一定覆盖双边费用和滑点，预算也不是最终亏损的保证上限。
“固定金额止盈”与“R倍数止盈”只选一种；如果终点低于后续阶梯，配置/运行预览会拒绝不可达规则。
3R后的条件判断与逐柱跟踪尚未启用，需后续提供判据后再实现。

## 4. 查看成交与原因

运行时进度条显示实际处理历史时间的比例，并列出计算日期、完成柱数、成交笔数、已用时间和多久未推进。
初次连接、读取历史、均线预热时可能无法计数，剩余时间明确标注“暂无法估算”；无成交也会按实际历史时间前进。
历史结束先显示“保存结果”，只有导出和完整性核对通过才显示100%。停止、断线、缺覆盖或保存失败不会标为完成。
持续模拟没有固定终点，只显示状态和已用时间，不显示虚构百分比。

勾选“观看交易过程（只读）”后，可以看K线、均线、实际成交箭头与保护线逐步出现。
图中只显示已处理的最近500根K线和窗口内最多5000条事件，全部记录仍留在SQLite；图表日期和计算日期分别显示。
收起／展开只影响观看，不重启计算、不增加账户连接，也不暂停风控。图表暂时读取失败时，可继续从主页面看进度。

进入“回测与比较”，点击保存的运行结果。
净收益已扣记录的费用；毛收益单列。期末没有自动平仓，未实现盈亏按SDK权益估值计入。
“完整交易次数”与“成交笔数”不同，只有本笔持仓实际归零才算完成一次交易。

点“查看成交K线（离线复盘）”，显示保存的K线、两条均线、成交箭头与保护价分段。
点击成交列表行可定位对应K线，点击图上箭头也可看原因。
原因区包含开平方向、成交量/价、交叉依据、初始R、档位和保护价。
形成中的柱会保存快照以定位最后一根上的成交，并明确标注；它不参与收盘交叉信号。
关闭软件后可重新打开同一运行复盘，不要求重新登录、取行情或重跑策略。
旧样例格式、损坏记录、缺少K线或数据版本不支持时明确提示，不用当前行情补造。

## 5. 复制与比较

先保存实验，再点“复制实验”，修改副本的快慢周期，例如5/20改为10/30，然后另行回测。
旧版跳数止损实验只能查看，点“复制为新版拐点实验”创建独立副本；升级会保留原来的上限并启用限制，需自行核对。
旧TOML和历史结果不会重写；新旧止损规则的收益不能直接当作同一策略的参数优劣。
保持合约、周期、日期、资金和费用一致，才能更清楚地看参数差异。
在结果列表勾选两个运行，点“比较所选两个运行”；页面列出净收益、费用、回撤、期末仓位及参数差异。

“附加独立双倍费用回放”是可选的成本压力实验：先保存基准结果，再独立按双倍SDK模型费用回放。
两次结果分别标记，不能把双费结果误当作原基准，也不能用它替代参数A/B比较。
不同区间、资金、精度、费用或完成状态会提示可比性问题。

## 6. 快期模拟

1. 进入“模拟运行”，重新查询和选择启动时核实的当前实际主力合约。
2. 不勾选允许委托时，点“连接模拟并观察”：只核对TqKq主模拟账户及数据，不发送策略委托。
3. 要运行策略，先确保整个快期模拟账户空仓且无未结委托，再勾选“允许本实验产生快期模拟委托”。
4. 点“启动模拟策略”并阅读确认；程序等待启动之后的新交叉，不追做已有历史信号。

模拟使用服务端真实模拟余额，不会重置为回测的10万元。
行情图下面的本地TqSim账户与TqKq主模拟账户不同，账户名称和资金来源要分清。
新旧研究窗口共享账户锁；同一主模拟账户串行使用，避免同时运行另一个客户端策略或手工干预。

“停止任务”取消执行任务及其未成交委托，不等于平仓。
“平仓并停止”只退出本实验拥有的模拟仓位，等待实际空仓且无挂单再确认；超时保留未决状态。
拒单、断线、主力变化、到期风险、外部操作或对账失败会冻结；本轮不自动换月。
窗口退出后本地止损保护不再运行。如需退出持仓，请先“平仓并停止”并核实确认。
异常中断、有持仓期间缺失风险记录或无法对账，不自动恢复、更不重放旧开仓目标。

## 7. 记录位置与验收边界

- 实验TOML修订：data/workbench/experiments/。
- 每次运行：results/<run_id>/，包含SQLite、CSV、元数据与简短报告。
- 本机凭证：Windows凭据管理器；不会写入上述实验和结果。

离线验收使用合成行情、内存凭证与真实图形组件；不证明实际账户权限或策略盈利。
本机联网顺序为：核对目录/合约→分钟近似回测→复盘/复制比较→模拟观察→显式模拟委托。
遇到权限或费用模型缺失先保留失败记录，不自动换样本或账户。本轮没有实盘入口。

## 8. 跨年度历史主力连续回测

新建研究实验默认版本3，选择品种、周期、起止交易日和仓位规则即可运行。
日期可以跨一年或多年；2025-03-03至03-07只是旧固定样例，不是用户日期限制。
已有版本1/2不会自动转换：选择旧实验后点“复制为主力连续实验”，创建新编号并保留原修订。
已保存实验的合约模式不能直接改写；连续实验只用于历史回测，模拟页仍使用固定合约版本2。

回放只创建一个TqBacktest和一个TqSim账户，初始资金只注入一次。
依据回放当时的主力映射选择真实月份，先确认旧仓平完和撤单，再按原方向、原手数开新。
新合约规格不兼容、资金不足、参考柱缺失或到期数据不可用时明确失败，不偷偷缩量或改日期。
起始日前的主力历史用于预热；预热不交易，数据不足不会当成策略没有信号。

连续信号图采用因果向前价差调整，月间价差不会直接制造交叉；过去信号不随以后换月重写。
调整后显示价格可能为负，属于信号坐标；实际委托、成交和详情仍使用真实合约正价格。
移仓标记可查看旧、新合约；成交箭头按该实际合约的偏移投影到信号图。
复盘可以选择连续信号图或某个实际合约，按日期定位或翻动窗口；首次2000根，客户端最多10000根。
运行图最多500根和窗口内5000条事件；完整原始证据仍在SQLite与CSV中。

例：初始R为1000元，已有平旧累计毛盈利C=1800元，现有保护要求至少锁500元。
接新后保护价按 `E+s×(500-1800)/(q×m)` 计算，其中E为新合约实际成交均价，
s为多空方向、q为实际手数、m为合约乘数。多单向上、空单向下取整到一跳，保持金额底线。
初始R与已达到的阶梯不重新计算；1800元毛盈利不是开了新合约就清零。
移仓进出都计入SDK费用，净收益以完整区间SDK账户权益为准；移仓手续费是总费用中的一部分。
“完整交易次数”按逻辑交易结束统计，单次移仓平旧不另算一次完整交易。

首次联网验收：正常退出并重开工作台，选择你实际需要的品种和跨年日期，先用分钟近似，
填写固定手数或风险预算，按需观看过程，然后运行；结果完成后核对换月次数、旧新成交顺序、
实际价格和费用，再复制修改均线进行比较。Tick精度单独核实权限，不会自动降级。
如失败，请查看状态中的日期、合约和原因；保存完成并核对通过之前进度不会显示100%。
本轮离线测试不能证明你的账户有全部年份的数据权限，也不证明策略盈利。
