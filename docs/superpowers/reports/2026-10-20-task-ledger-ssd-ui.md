# 任务观察、逐笔交易账本与SSD存储交付记录

## 已完成

- 账户表改为按内容签名和稳定行键增量更新。相同持仓、委托和成交快照不再清空表体，
  避免闪烁并保留当前标签页和滚动位置。
- 每个回测任务拥有独立的本机只读图表服务；任务卡新增“独立窗口”，通过默认浏览器
  同时打开多个任务图。关闭主工作台后，实时图服务随主进程停止。
- 新增逻辑交易账本，从 `logical_trades`、`logical_fills`、`fills`、
  `research_fill_fees`、`risk_events` 和 `contract_specs` 还原：
  开平时间与均价、手数、初始止损、最终保护、退出原因、手续费、毛盈亏和净盈亏。
- “成交记录”显示每次实际成交的本笔手续费和所属交易净盈亏；“交易明细”显示完整逻辑交易。
  账本费用合计必须与账户累计手续费核对，差异会显示黄色警告。
- 回测结果默认写入 `%LOCALAPPDATA%\TqStrategyWorkbench\results`，首次运行复制项目旧结果，
  原目录保留。设置页可直接打开研究结果目录。
- 回测 SQLite 使用 WAL `NORMAL`；模拟执行继续使用 `FULL`。账户分钟采样只保存汇总，
  完整持仓、委托和成交在成交、风险变化及末次快照保存。

## 验证

- 账户表真实 WebView2 联调：连续两次轮询后，同一行的 DOM 节点保持不变；切换标签页后
  仍可查看成交费用、所属交易净盈亏、开仓/平仓价、止损和退出原因。
- 两个任务分别创建独立 `LiveResearchView`，关闭管理器时全部释放。
- 使用用户已有两组回测记录核对：逐笔手续费合计分别为 `2111.148`、`5925.816`，
  与账户累计手续费差异均为 `0`。
- SQLite 微基准（D盘机械硬盘，1000次单行事务）：`FULL` 约 `35.36秒`，
  WAL `NORMAL` 约 `0.14秒`。该数字只说明提交同步方式的差异，不代表完整回测加速倍数。
- 全量 `tools/check.ps1`：`544 passed in 346.04s`，Ruff、环境、依赖锁和135项原生资源检查通过；
  真实浏览器多窗口、真实账户多年数据权限和新SSD目录下的
  长时间联网回测仍待用户本机验收。

## 边界

- 单个策略回测仍按 SDK 事件顺序和持仓状态串行推进；GPU 不参与因果回放。
- 并行实验使用多个工作进程利用 CPU，不共享资金和保证金，不能把独立任务收益相加。
- 外部浏览器窗口依赖默认浏览器；关闭主工作台后不再接收实时快照。
