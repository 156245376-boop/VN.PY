# 可选技术指标与成交量分布设计

日期：2026-10-18。
状态：功能范围、估算 VP 路线已获用户确认；本正式设计待审阅，尚未实施。

## 1. 目标与范围

用户希望在当前天勤行情图中选择加载常用指标、修改参数，并同时观察均线、VP 和多个副图。
保留已经完成的分屏、画线、历史浏览和图表/账户高度拖动；本轮只增加研究显示能力。
现有示例策略、回测及模拟执行不自动采用这些指标，不因图上显示指标而产生委托。

第一版采用现有 K 线估算 VP，始终显示“估算”及计算周期。它不能还原真实逐价成交量。
继续使用 Python 3.13.11、TqSdk 3.10.2、现有只读行情会话和四格工作区。

## 2. 复用选择与依据

采用“天勤计算函数 + 当前原生图表 + 项目负责的指标交互与绘制适配”。

| 路线 | 决定与原因 |
| --- | --- |
| 复用天勤公式并扩展现图 | 采用。常用公式已有，现有坐标、画线、历史保护可以继续使用 |
| 整体换图表库 | 不采用。需要重新验证现有历史、分屏、画线和价格轴行为 |
| 从头编写整套公式和 VP 引擎 | 不采用。优先使用已存在的计算实现 |

本机 `tqsdk/ta.py` 已确认包含 MA、EMA、BOLL、SAR、MACD、KDJ、RSI、ATR、CCI、DMI、OBV。
简单移动平均使用 `ta.MA`；SDK 的 `ta.SMA` 是另一种平滑公式，不混用名称。
原生 `demo/tutorial/t91.py` 提供指标线、颜色、线宽和独立副图的示例；它是接入参考，
不能据此假定同合约不同格的参数能直接共用同一个服务端序列字段。

已搜索官方技能目录、技能市场、插件目录及开源仓库。找到的相关技能主要面向技术分析、
订单流说明或 TradingView/PineScript，尚未发现经过核实、可直接接入当前 SDK 网页的完整指标插件。
因此不安装不适配的全套技能或另一个行情/交易服务；现有官方 TqSdk 技能继续用于开发。

VP 选用 `MarketProfile==0.2.0` 作为复用目标，通过项目安装入口锁定依赖；不裸 pip，不升级 SDK。
发布版必须先在当前解释器和已锁定 pandas/numpy/scipy 下验证；与接口或数值不兼容时停止该项，
说明具体失败，不自动换公式或换数据源。上游采用 BSD 许可，保留所需版权与许可说明。
未执行兼容性验证或安装，不能将本设计中的库选择写成“已接入”。

## 3. 指标清单与初值

初值用于便于操作，不代表已验证的交易参数。除成交量和持仓量外，首次启动不自动开启其他指标。

| 位置 | 指标 | 初始参数 |
| --- | --- | --- |
| 主图 | 简单移动平均 MA | 5、10、20、60；支持增减，最多 8 条 |
| 主图 | 指数移动平均 EMA | 12、26；支持增减，最多 8 条 |
| 主图 | 布林带 BOLL | 周期 20、倍数 2 |
| 主图 | 抛物线 SAR | 周期 4、步长 0.02、上限 0.2 |
| 主图 | 成交量分布 VP（估算） | 屏幕范围、右侧、自动分档、宽度 25%、透明度 45% |
| 副图 | MACD | 12、26、9，柱值沿用 SDK 的 2×(DIFF−DEA) |
| 副图 | KDJ | 9、3、3 |
| 副图 | RSI | 周期 6 |
| 副图 | ATR | 周期 14 |
| 副图 | CCI | 周期 14 |
| 副图 | DMI | 14、6 |
| 副图 | OBV | 沿用 SDK 公式；标明累计数据的起点 |
| 副图 | 成交量 | 每根 K 线的 volume，单位手 |
| 副图 | 持仓量 | 每根 K 线的 close_oi，单位手 |

成交量与持仓量可在同一副图使用各自坐标轴，保持当前常用观察方式；关闭一项只隐藏对应序列。
MACD、RSI 等不同量纲的指标分别有自己的副图，不把数值混用同一纵轴。
主图价格类指标使用该品种报价单位，ATR 使用相同价格单位，其余副图按公式标明单位或无量纲。

## 4. 操作与多格行为

每格标题栏增加“指标”入口，打开该格的指标面板；不展开全局页面导航。
面板包含可添加目录、当前已加载项、显隐、参数、颜色、线宽、删除和恢复该指标默认参数。
新增指标不取消其他项；主图可同时加载 MA、EMA、BOLL、SAR 和 VP，副图可同时存在。
参数提交前集中验证；非法参数保留上次有效结果并说明原因，不清空整个图表。

每种常用指标每格一个实例，多条均线放在该实例内管理；VP 每格最多两个实例，
允许同时观察一个固定区间和一个屏幕范围，标签区分两者。其余同类重复实例不在第一版范围。
周期参数为 1–1000 的整数；MACD 短周期小于长周期；SAR 步长为正且不大于上限。
参数滑动/连续输入合并，在提交或短暂停顿后计算，不对每次按键重建图表。

每格保留独立配置；品种联动仍只联动品种，不覆盖其他格的指标或参数。
切换品种时常用指标设置继续使用，结果重新计算；固定 VP 的区间绑定完整合约标识，
换到另一真实合约、主连或换月后进入“请重新选择区间”，不把旧区间套到新合约。
同一合约切换周期时保留区间时间锚点，按新周期数据重新估算并标明周期变化。

副图按面板中的顺序显示，可调整高度；空间不足时使用格内滚动和最小可读高度，
不通过等比例缩放整幅图像腾空间。单格放大、工作区放大及账户分隔条继续有效。
添加或隐藏指标只更新受影响的图层，不更换 iframe 地址，不重新认证，不改变连接灯含义。

## 5. VP 的估算和显示规则

### 5.1 计算口径

固定采用所选范围内“当前周期 K 线收盘价所在价格档位 × 该柱总成交量”的归集口径，
复用 MarketProfile 的成交量模式；不把总成交量均匀分摊到未知成交价格，也不冒充逐笔成交。
界面说明为“VP 估算 · 按收盘价归集 · 当前周期”。周期变化可能改变归集结果，
因此不承诺相同时间段在日线与分钟线上的估算分布相等。

价格分档不小于合约一跳，为一跳的整数倍。自动模式根据所选数据的价格范围目标分为约 64 档；
用户可指定每档包含 1–10000 跳；输出最多 512 个价格档，过细时提示调整，不暗中修改指定参数。
价格档归集边界沿用所锁定库的规则，显示档位范围和方法；浮点误差不得把本应同档的有效报价分开。
输出总量必须与参与计算的有效 K 线 volume 总和一致；零量范围显示“所选范围没有有效成交量”。

### 5.2 范围选择

- 屏幕范围：按当前可见 K 线的时间区间统计；拖动、滚轮或年份定位稳定后更新。
- 固定区间：选择工具后在主图点两个时间位置，显示半透明选区；端点可拖动，支持直接输入北京时间起止。
- 选区按完整 K 线时间区间处理，最后一根包含其实际结束边界，不按柱数倍乘推测其他周期。
- 选择期间左键用于选区，不同时平移图表或启动普通画线；完成、取消或 Esc 后恢复原鼠标模式。
- 固定区间不因普通图表平移变化，两个端点使用真实时间锚定；区间在图外时仍可在面板编辑或定位。

统计使用范围内全部已验证价格，不只统计当前纵轴可见价格；绘制时裁剪到主图可见价格域。
不通过裁掉价格档重新计算百分比或暖色，避免用户上下调价格轴时改变分布含义。
所选区间尚未完整返回时显示所需/实际范围并暂停该 VP 的结果；不把缓存交集当作完整区间。
第一版使用已有图表历史加载流程，缺少的范围须先在图表加载；不引入付费下载或额外历史数据源。

### 5.3 长度、颜色与标注

左右位置独立可选，宽度为主图可用宽度的 10%–40%，透明度为 10%–90%。
每个实例中最长横条对应最大档位成交量，其余长度按该最大值线性缩放。
颜色按同一实例的成交量比例从蓝到黄、橙、红单调变化，最大档位为最暖色；零量档不画横条。
颜色只表达成交密集度，不表达主动买卖方向；不从 K 线涨跌伪造买量、卖量或 Delta。
悬停显示档位价格范围、估算成交量（手）、占本范围总量比例、区间和计算周期。
最大量价位线（POC）可单独开关，最大量并列时沿用库的确定性规则。
价值区域、主动买卖拆分、订单流足迹和自动交易信号不在本次范围内。

## 6. 数据流与组件责任

1. 指标目录：维护上述有限白名单、中文名称、默认值、参数范围、输出含义与单位。
2. 配置与面板：每格独立管理已加载实例、参数和样式；不持有 SDK 认证对象。
3. 子页适配：从当前已核实的原生图表缓存提取 OHLCV、持仓量、时间、编号及当前可见范围，
   使用现有来源/窗口身份校验向父页提交；不给原生子页新增 Python 业务桥接。
4. 父页调度：校验消息来源、pane_id、generation、合约、周期、图表 revision 以及指标配置版本。
   通过可信主页面桥接提交纯计算请求；父页及后端都校验字段和大小上限。
5. 计算模块：只接受白名单数值序列和参数，用 `tqsdk.ta` 与 MarketProfile 计算；
   不创建 TqApi、不订阅、不读取凭证、不执行用户表达式或动态函数名。
6. 绘图适配：主图线与 VP 使用原生图表当前时间/价格坐标；副图与原图使用同一横向映射，
   各自纵轴。项目拥有绘制层及生命周期，不修改 SDK 安装资源，不复制整个上游前端。

项目图层必须与原生 canvas 的实际价格和时间坐标一致，不能按 iframe 尺寸直接线性猜价格。
主图价格类指标参与自动价格范围；用户手动调整价格域时遵守原有手动域，VP 不强制扩展价格轴。
普通画线置于指标上层；VP 仅在柱条上处理悬停，不拦截图表其他区域的拖动、滚轮或画线控制点。

计算由独立受限工作线程处理，全局最多一个正在执行的任务；每格最多保留一个最新待处理请求。
每次最多 20000 根输入柱、512 档 VP；持续拖动按约 250ms 合并，行情更新最多每格每秒计算两次。
相同数据版本与配置不重复计算；隐藏格不计算。陈旧结果必须丢弃，不能覆盖用户后来的选区或参数。
计算异常只影响对应指标，原行情图继续显示；连接中断或原历史核验失败时撤下已不可信结果并提示。

可见范围外为常用指标提供最多 1000 根已加载预热柱；历史起点有限时使用 SDK 对该实际输入的结果。
公式仍为 NaN 的点留空，不以零代替，不跨缺口连线。有限起点影响 EMA、MACD、RSI、OBV 等，
面板标明实际计算起点与预热不足，不能称为从上市日起精确累计。
可见柱加预热超过输入上限时提示缩小范围；不静默采样、截断 VP 区间或把不完整结果标为完成。
正在形成的 K 线可用于动态图形，读数标明“未收盘”；本次不把显示值送入策略信号链。

## 7. 配置保存与安全

使用独立 `data/workbench/chart-indicators.json`，schema=1，按固定 pane-1 至 pane-4 保存配置。
不修改现有严格的 `chart-workspace.json` schema，避免已有布局、自选或分屏比例被判损坏。
保存白名单包括指标类型、参数、样式、顺序、副图高度以及固定 VP 的合约与起止时间。
不保存行情数组、计算结果、认证、令牌或 SDK 对象。纳秒时间锚点以十进制字符串保存，避免 JS 整数精度损失。
文件缺失使用成交量/持仓量初始显示；格式损坏保留原文件、明确提示并阻止自动覆盖。
沿用原子保存与串行合并思路；退出统一等待布局和指标保存，保留现有退出确认与时间上限。
恢复设置不自动登录、不启用策略，不在离线测试中覆盖用户的真实布局与指标文件。

## 8. 验收要求

| 类别 | 必须满足的结果 |
| --- | --- |
| SDK 复用 | 常用输出与同输入下官方函数一致；MA 与 SDK SMA 不混用；MACD 柱值口径明确 |
| 预热与质量 | 缺柱、倒序、无效价、负成交量、NaN、零量和过大范围有明确结果；不伪造零值 |
| VP 估算 | 小样本手工核对档位和总量；一跳、小数报价、边界、并列最大量都可复现 |
| VP 外观 | 左右可切换；条长和暖色均随相对成交量单调增加；提示显示价格和手数 |
| 时间范围 | 固定选区端点可编辑；屏幕模式跟随视口；换周期保留时间但说明估算差异；缺数据不截取冒充 |
| 同时加载 | MA、BOLL、两个 VP 与 MACD/RSI 等可共存；删除一项不影响其他项或重建 iframe |
| 四格隔离 | 同合约、同周期、不同参数互不覆盖；切换格、品种、周期后的迟到结果被拒绝 |
| 已有交互 | 画线编辑/跨周期、右键、自选、滚轮、拖动、价格轴、账户分界和放大/还原继续可用 |
| 布局稳定 | 多副图的普通/放大、双图/四宫格、DPI 小数边界持续采样无滚动条循环或反复加载 |
| 保存退出 | 重开恢复设置；坏文件保留；快速修改和退出不丢最后已提交配置；确认退出正常结束 |
| 依赖与隐私 | 仅项目入口安装；SDK 版本和资源哈希保持；凭证不进入请求、测试证据、日志或配置 |

先进行库兼容与公式验证，再做带合成行情的真实 WebView2 离线交互回归，最后执行 `tools/check.ps1`。
账户联网的行情更新需另记实际结果；离线通过不代表开盘实时、策略验证或模拟/实盘交易通过。
