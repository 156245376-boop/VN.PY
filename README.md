# 个人期货策略研究：天勤路线

使用 Python 和天勤 TqSdk 验证国内期货分钟级策略，再逐步进入模拟与自动交易。
旧成果已封存；现有独立环境和研究到模拟的运行入口，待用户本机凭证联网验收。

## 日常使用：双击窗口

双击根目录的 **启动天勤.vbs**。无需管理员权限，也不用先打开 PowerShell。
窗口中输入快期账号和密码，然后选择：

- **连接并观察**：连接唯一快期主模拟账户，自动打开天勤图形网页，不产生委托。
- **运行示例回测**：先基准费用，再双倍费用；第二次回放自动打开天勤原生图形页面。
- **启动模拟策略**：明确允许示例策略发送模拟委托，最多多头 1 手；新实验仍要求空仓无挂单。
- **停止运行**：合作式请求停止，等待连接步骤和撤单收尾，不强杀后台、不自动平仓。
- **查看天勤图表**：重新打开本次运行的本机图形页面。
- **打开实验目录**：查看 SQLite、CSV、报告和费用比较结果。
- **天勤现成功能**：无需登录即可检查原生组件、阅读官方示例及查看权限和文档。

窗口保持响应，展示中文阶段及运行心跳。凭证仅在当前窗口内存，不保存到磁盘或命令行；
关闭窗口即结束本次使用。原始 SDK 通知和认证输出继续屏蔽。
页面只监听本机 `127.0.0.1`，不是公开网站，不需要上传账户数据。

回测结束后，先停止策略执行并保留最后一次天勤页面，状态显示“回测完成”。
看完后点击 **结束查看并保存结果**；窗口会关闭会话并展示基准/双费结果摘要。
停止或关闭会话后，天勤实时页面不再提供服务；本地报告和实验记录仍保留。
回测图表对应双倍费用实验，基准结果及完整比较见窗口“结果摘要”和实验目录。

首次使用建议先“连接并观察”，确认页面和账户，再运行回测。新窗口默认不启用模拟委托。
图形入口复用现有策略和保护，不提供实盘账户选择。

登录窗口和操作按钮是本项目的入口；浏览器行情、账户和回测图形来自天勤原生界面。
现成组件、86 个官方示例及其额外依赖已备齐，说明见 [天勤现成功能](docs/tqsdk-native-kit.md)。

## 环境操作

Windows、PowerShell、uv，Python 固定为 3.13.11，TqSdk 固定为 3.10.2。
在项目根目录执行：

```powershell
.\tools\setup.ps1
.\tools\check.ps1
```

安装脚本使用提交的锁文件，不默认升级。新环境为 `.venv-tqsdk`；
原 `.venv` 保留在原位置。脚本显式选择新环境并恢复进程环境变量，
不依赖终端是否激活旧环境。不要在此项目直接执行裸 `uv sync` 或 `pip`。

只有维护者首次生成新锁、且根 `uv.lock` 不存在时，才使用 `setup.ps1 -InitializeLock`。
该开关拒绝覆盖已有锁文件。
依赖发生明确变更时使用 `setup.ps1 -UpdateLock`，不默认升级已有依赖；
默认安装包括 `dev` 与 `official-examples` 依赖组。检查也覆盖原生组件、示例和网页资源。
若检查发现 SDK 资源损坏，先关闭工作台，再运行 `setup.ps1 -RepairSdk` 重装锁定版本。

## 当前范围

检查成功表示封存包完整、解释器与 SDK 正确、锁定依赖一致及工具测试通过。
它不表示已经登录天勤、收到行情、验证策略或具备实盘权限。
期货开户可独立办理，后续依据开户材料安排接入与外接测试。
账户密码只在本机安全输入，不发送到聊天。

## 首次联网操作（PowerShell）

以下入口保留给开发和排查；日常使用可以直接用上述窗口。

先做只读检查：

```powershell
.\tools\run.ps1 data-check
```

在终端提示时隐藏输入快期账号和密码（不是期货资金账号）。成功输出 `data_ready`，
包括螺纹主连对应真实合约、行情时间、完成分钟时间，实验文件在 `results/<run_id>/`。
只证明当前订阅可读，不推定全部历史权限。若 30 秒内无数据或权限不足，明确失败。
也支持仅本进程已有的 `TQ_USER` / `TQ_PASSWORD`；不要把明文赋值写进命令历史、脚本或配置。
CLI 不接受命令行密码参数，SDK 原始通知和异常不会写入终端或实验文件。

再做固定样本回测：

```powershell
.\tools\run.ps1 backtest
```

公开配置是 `experiments/rb-demo.toml`：SHFE.rb2505，2025-03-03 至 2025-03-07，
本地初始 10 万。完成分钟 close 高于含该柱的 15 柱均线，目标多 1 手，否则 0。
不足预热不交易；只使用形成中柱前的数据。这是链路示例，不证明策略盈利。
成功会独立执行基准、双倍每手费用两次回放，分别生成实验目录。
基准目录的 `comparison.md` 和 `comparison.json` 提供比较；每次都有 `metadata.json`、
`journal.sqlite3`、信号/成交/委托/权益 CSV 与 `report.md`。
元数据记录配置、代码提交、工作树改动摘要和源码指纹；信号行保存完整计算窗口。
SDK 模拟费用与保证金非历史真实成本；本地撮合不产生部分成交，分钟盘口可能合成。
结束按市值估值，不自动平仓；总费用来自 SDK 全区间统计，非最后交易日费用。

最后在交易时段观察快期模拟：

```powershell
.\tools\run.ps1 paper -Duration 300
```

输入完成后会显示 SDK 加载、账户连接、数据就绪及观察开始；运行时每 15 秒显示心跳。
300 秒从账户和行情数据就绪后开始计算，不包含登录和收尾时间。
心跳只说明本机循环仍在运行，最新行情时间以数据和最终实验记录为准。
SDK 原始通知和认证内容继续屏蔽，进度输出只包含固定提示及运行秒数。

默认只观察、不创建目标执行任务。使用服务端实际余额，不能把快期模拟资金改成 10 万。
新实验要求整个主模拟账号空仓且没有有效委托；不会自动清旧仓。使用一个账户锁串行运行，
不要同时从其他电脑或快期客户端操作这个模拟账户；本机锁不能阻止远端人工操作。

只读和回测确认后，显式启动**模拟委托**：

```powershell
.\tools\run.ps1 paper -Activate -Duration 300
```

不传 Duration 时持续运行。Ctrl+C 请求取消任务并等待撤单确认，可能保留实际模拟持仓，
不表示平仓；退出后核对 `final_positions` 和 `cancellation_confirmed`。
超时、拒单、断线、映射变化、未知持仓/委托/成交都会冻结，冻结后不会自动恢复。
运行中的应用逐笔守卫只允许对应真实螺纹合约、多头最多 1 手；没有实盘账号参数。
首版不自动换月，到期前一天停止，后续再单独验证正式到期规则。

干净停止后，当日恢复同一实验先观察，再决定显式启用：

```powershell
.\tools\run.ps1 paper -Resume '<run_id>' -Duration 60
.\tools\run.ps1 paper -Resume '<run_id>' -Activate
```

只允许原快期身份、原配置与源码指纹、原真实合约、完整记录、无未决委托且成交和持仓一致。
被强制结束、非干净退出、跨日离线或未知操作会保持冻结；不要通过修改数据库绕过。
新进程不会重复处理已记分钟或重放旧目标。服务只提供当日成交，离线缺口不能假装已补齐。
每次恢复先观察且不会接着执行遗留目标；已有仓位将等新的完成柱再决定下一目标。

运行时退出状态 `failed` / `frozen` 是失败，不是已撤单或已清仓。
错误文本只给脱敏类别：`sdk_or_auth_or_permission_error` 需本机核对认证/权限；
`data_timeout_or_permission_unavailable` 表示数据未就绪；`cancellation_unconfirmed`
需在快期模拟客户端核对挂单。不要把原始认证响应发到聊天。

## 当前验收边界

自动检查覆盖信号、SQLite 去重、账户锁及 SDK 边界替身演练。
已在本机完成一次快期主模拟账户只读连接及行情/分钟数据就绪核对。
历史回测权限、模拟委托、长时间运行和远程故障仍待验收，不能据此认为实盘可用。
银河账户审核和外接测试可并行；本项目无实盘运行入口，实盘范围另行确认。
后续增量依次是个人策略规则、多品种共享资金、批量参数与样本外验证。
