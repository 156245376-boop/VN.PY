# 本机窗口登录与天勤图形页面

用户已选择：双击启动、窗口登录，再打开天勤图形页面。
基线：04c29ca；沿用当前 codex/research-paper-loop 工作区与独立环境。

## 交付

1. 双击入口打开轻量中文窗口，不要求 PowerShell；复用现有 Python/TqSdk，不增加依赖。
2. 凭证只在窗口本次运行内存；密码遮挡、不经命令行/文件保存；UI 与 SDK 分线程。
3. 提供连接观察、固定样本回测、显式模拟策略、停止、查看天勤图表、打开实验目录。
4. SDK 原生 web_gui 只监听 127.0.0.1；自动打开官方本机页面，保留原策略/保护边界。
5. 回测完成后先禁止执行，再继续驱动页面供查看；点击停止/关闭后清理服务。
   基准与双费回放仍串行，各自有结果；界面提供已保存报告摘要。
6. 不修复此次明确延期的 P2 委托排队问题；不增加实盘入口。

- 测试先行：后台运行隔离、凭证不外泄、并发启动拒绝、停止事件、白名单输出。
