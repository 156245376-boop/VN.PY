# 行情显示与单位核对

更新：2026-10-17，适用于当前只读行情工作台。

- 绿灯：行情服务已连接；黄灯：正在连接或断开；红灯：未连接、已断开或连接失败。
  是否收到某个品种的报价单独显示，绿灯不代表所有品种均有新数据。
  天勤内嵌页原有两灯明确标为“图表服务”和“图表行情”，分别表示图表页面服务与图表行情通道。
- 报价时间显示北京时间的完整日期与时分秒。休市时可显示最后收到的报价，不用无新 Tick 推断断线。
- 未返回有效价格和时间的品种显示“暂无有效报价”；默认成交/持仓零值不冒充已收到的数据。
  未经明确返回，不将空值推断成权限不足、休市、暂停交易或价格为零。
- 当前页、自选、图表标明报价单位；成交量及持仓量为手，涨跌幅为百分比。
  国债使用“元/百元面值”说明百元净价口径。报价单位不等于一手合约价值。
- `qf/market_units.py` 按交易所和品种列出白名单。未收录品种显示“单位待确认”，不把所有商品默认为元/吨。
  当前标准用于当前行情展示，不作为过去每个合约历史规则的证明。

## 本次修正

缓存目录先到达时的空选择不再阻止默认合约加载；前后端均补默认选择，保留用户已选品种。
仅在图表旁提供“放大 K 线”，Esc 还原，放大不重建行情会话。
天勤工具栏的原固定宽度不适合中文长名称；改为随图表宽度排布且保持单行，窄窗口可横向滚动，避免覆盖 K 线价格文字。
外层选择品种时通过原生订阅按钮同步到对应实际合约，不再依赖天勤随机收到的首个订阅项。
连接反馈来自当前会话状态，不保留登录时的“正在连接”提示。
单个合约 K 线读取失败只提示图表不可用，不停止其他正常报价，也不输出原始认证异常。
