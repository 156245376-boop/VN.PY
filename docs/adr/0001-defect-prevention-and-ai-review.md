# ADR-0001:降低缺陷率的手段优先级,以及自动化代码审查的定位

状态: 生效
日期: 2026-08-30
承重性: **承重** —— 决定全项目测试用例的可信度来源。若推翻此决策,现有全部表驱动测试的证明力需重新评估

## 背景

本系统由一人开发,借助大语言模型编写绝大部分代码,且真实资金参与运行。需要确定一套缺陷预防机制。

一个自然的候选方案是:引入自动化代码审查(子 agent)作为主要防线,在每次代码变更后审查实现是否正确。

约束条件:
- 开发者一人,任何仪式性流程都会直接拖慢收敛速度
- 本项目会亏钱的缺陷集中在领域规则理解错误,而非代码逻辑错误
- 免费数据源与交易所规则的权威资料需人工获取

## 决策

缺陷预防手段按可靠性分四级,**按此顺序投入,不越级替代**:

1. **确定性检查** —— 分层依赖检查、文档与 `__all__` 一致性检查、静态类型检查、格式检查
2. **表驱动测试,预期值由人工依据外部权威资料核对确定**
3. **与外部真相的交叉校验** —— 交易所日行情文件、本账户 CTP 查询返回的实际费率、实盘真实成交
4. **定向的自动化代码审查** —— 提供外部判据,执行比对而非判断

自动化代码审查**不作为每次代码变更的前置条件**,仅在模块完成与 Phase 完成两个节点执行。

## 理由

**核心理由:大语言模型审查大语言模型的产出,其盲点是相关的,不是独立的。**

若实现者对上海期货交易所平今规则的理解有误,审查者以**同样错误的理解**读同一段代码,会审查通过。而本项目会亏钱的缺陷恰好全属此类:

```python
def to_trading_day(dt, exchange):
    if dt.hour >= 21:
        return next_trading_day(dt.date())   # 周五夜盘在此处错误
```

这段代码在逻辑上无可指摘,读起来完全合理。它的错误是**与现实不符**,而非与自身不符。同类缺陷还包括:以收盘价替代结算价、Bar 时间戳偏移一分钟、换月决策使用了当日数据。这些代码都很干净,静态审查看不出问题。

由此推出两条:

- **凡可由脚本判定的约束,一律用脚本**。脚本无假阴性、零成本重跑、不受上下文长度影响。在这类任务上,自动化审查更贵、更慢、且更不可靠。
- **测试用例的预期值必须引入系统外部的真相**。若预期值由生成实现的同一模型产出,测试退化为"模型的理解 == 模型的实现"的同义反复,证明力为零。因此约定:测试的输入与结构可由模型编写,**预期值留空并标记待填,由开发者查阅日历、交易所公告等外部资料后填入**。

自动化代码审查仍有价值,但价值来自**为其提供外部判据**,而非依赖其自身判断:

| 用途 | 提供的判据 | 有效原因 |
|---|---|---|
| 验收标准覆盖检查 | `requirements.md` 中某条需求的验收标准原文 | 判据在审查者之外。本项目验收标准为 EARS 格式且可测试,可直接充当检查清单 |
| 领域规则核对 | 开发者提供的交易所规则原文、券商确认的费率表 | 针对的正是上述相关盲点类缺陷,但**前提是开发者已获取权威资料** |
| 变更审阅 | 无历史上下文地阅读改动 | 检出长会话中的意图漂移与文档不一致。价值中等,存在噪音 |

开放式提问("看看有没有 bug")无外部判据,同时承受相关盲点与高噪音两项缺陷,不采用。

## 放弃的方案

- **以自动化代码审查为主要防线,每次变更均审查**:盲点与实现者相关,对本项目最危险的那类缺陷无检出能力;且给每次提交附加审查仪式,是一人项目中典型的"看似专业、实际拖慢收敛"的做法。本项目已识别的最大失败风险为"永不上线的半成品",此方案直接加剧该风险。
- **由模型生成测试用例的预期值**:执行成本最低,但使测试成为同义反复,且该缺陷不可观测 —— 测试会全部通过。
- **完全不引入自动化代码审查**:放弃了验收标准覆盖检查这一项确有价值的用途,该用途的判据来自需求文档而非模型自身。

## 后果

好的方面:
- 领域逻辑的正确性锚定在系统外部的权威资料上,而非模型的理解上
- 确定性检查承担了可自动化的部分,秒级反馈,可在每次变更时执行
- 开发节奏不被审查仪式拖累

坏的方面:
- **人工核对预期值是本机制中唯一无法自动化、且必须由开发者亲自完成的环节。** 该环节失效则整套测试的证明力归零。其中「完全跳过」这一种失效已由 R34.7 转为可观测(待填标记使测试失败);但「敷衍填入」——照抄实现当前的输出、或向模型索取取值——**仍然不可观测,且测试会全部通过**。这是本决策最主要的执行风险,无技术手段可缓解。
- 交叉校验依赖交易所日行情文件、CTP 查询结果等外部数据可得,数据缺失时该级防线暂时失效
