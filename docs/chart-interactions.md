# 价格轴、分隔条与右键画图

针对锁定的 TqSdk 3.10.2 嵌入图表，适配代码为 `qf/web/native-tools.js`。
宿主在本机子页注入，由既有原生图表适配调用；不修改 SDK 安装资源、不接入账户桥接或委托。

## 使用方式

- 拖动 K 线与账户区域间的分隔条：拉高时底价不变，价格单位与像素比例保持，上方露出更多价格。
  拉低则收窄范围；会重新绘制图形，不拉伸蜡烛。
- 左侧显示有效整数粗刻度，右侧按可见高度显示更细的刻度，最细为合约的最小变动价位。
  两侧使用同一价格域；标签过密时增大刻度间隔，不制造小于一跳的报价刻度。
- 主图右键打开菜单，选择水平线、趋势线或矩形。水平线点击一次，趋势线与矩形分别选两个点。
  价格选点对齐合约的一跳，横坐标对齐实际 K 线时间；虚线预览表示尚未完成。
- 绘图时图内提示当前工具。点击提示上的取消、右键菜单“取消画图”，或按 Esc，可放弃未完成的一笔，
  恢复左键拖动；已完成画线保留。滚轮仍调整 K 线疏密。
- “撤销上一笔”删除本图最近完成的一笔，“清除本图画线”删除当前品种和周期的研究画线。
- 右键“恢复价格自动适配”，或双击右侧价格轴，恢复按可见 K 线计算价格范围。
  切换品种、周期或横向浏览范围后，也重新按该范围自动适配。

画线保存在当前图表会话的内存中，按品种、周期和图形类型隔离；切回来可以继续查看。
关闭窗口、重建图表页面或重新连接时不承诺保留，尚不包含落盘保存、移动已完成线段或自动识别支撑阻力。
画线只用于研究标记，不影响策略信号、模拟委托与回测成本。

## 校验边界

原生 `resize/resetByKlineId` 可能同时调整一根 K 线的左边界；保持纵向比例时不能因此误判为用户横向导航。
绘图层使用时间戳定位缓存中的实际柱编号，避免拉取历史后柱编号变化导致画线漂移。
原生拖拽事件仅在浏览模式接收左键；右键不能启动原生的 100ms 延迟拖拽。

离线 Node 回归覆盖纵向范围、整数与一跳刻度、鼠标模式互斥、Esc、撤销/清除、品种隔离、矩形及缓存重编号。
真实 WebView2/SDK 集成使用本机合成 K 线和脚本鼠标事件，阻断外部 WebSocket；操作实际分隔条，
核对价格比例、两侧坐标、菜单、绘图、取消后的拖动与滚轮，并确认子页没有业务桥接。
本项不创建账户会话；离线模拟数据的显示不代表行情或交易账户验收。

统一检查入口仍为 `tools/check.ps1`。
