# 图表指标与估算成交量分布

每个图表格右上角点击“指标”，选择种类后点击“添加指标”。可同时加载多个主图指标和副图；四格各自保存设置，品种联动不复制其他格的参数。

| 位置 | 可用指标与初始参数 |
| --- | --- |
| 主图 | 简单均线 MA(5、10、20、60)、指数均线 EMA(12、26)、布林带 BOLL(20、2)、SAR(4、0.02、0.2)、估算 VP |
| 副图 | MACD(12、26、9)、KDJ(9、3、3)、RSI(6)、ATR(14)、CCI(14)、DMI(14、6)、OBV、成交量、持仓量 |

MA 是简单平均，不是天勤的平滑 SMA。MACD 柱使用天勤的 2×(DIFF−DEA)。常用指标直接调用已锁定的 `tqsdk.ta`；VP 复用 MarketProfile 0.2.0，许可见 `third-party-notices.md`。

在已加载项目中可显隐、删除、上下调整、恢复该项默认值，修改颜色、线宽及参数。均线周期用逗号分隔，支持 1–8 条；周期为 1–1000。参数校验通过后才提交。副图高度可设置或拖分隔条调整，最低 120 CSS 像素；副图过多时在图表内部滚动。

## VP 使用

- 每格最多两个 VP，可同时显示固定区间和屏幕范围。模式、左右、分档、宽度、透明度及 POC 开关均在指标面板中设置。
- 屏幕范围随当前实际可见 K 线计算。固定区间可点“图上选区”后用左键选两端；拖动端点可编辑，也可输入北京时间起止时间并应用。
- 选区期间左键用于选点；Esc、取消或失焦取消未完成操作并恢复平移。已确认区间按真实时间保存，跨周期保留；换完整合约后须重新选择。
- 横条越长代表该价格档量越大，最大档接近红色；冷热不代表买卖方向。可在左右显示，宽度为图宽的 10%–40%，透明度 10%–90%。悬停显示时间范围、周期、价格档、手数与占比。

VP 始终是**估算，按收盘价归集**：把每根柱的全部成交量归入收盘价所在档，不是逐笔逐价成交量，不提供主动买卖量或 Delta。切换周期后估算可能不同。自动分档目标约 64 档；可指定每档 1–10000 跳；最多 512 个价格档，过细时暂停该 VP，需调大分档。

## 数据、保存与验证边界

指标只消费已核实的原生缓存，不新增行情或账户会话。每次最多 20000 根输入，常用指标加入最多 1000 根已加载预热柱。图上显示实际计算起点；首段可能不足预热，OBV 从该起点累计，不能跨不同计算起点直接比较。末根可能未收盘，会随行情改变。

缺柱、无效数值或断线时暂停不可信结果；NaN 留空，不画成零。固定区间必须完整覆盖，缺数据或超过上限不会截取部分冒充完整 VP。单项公式或 VP 出错不影响其他指标。

设置在本机 `data/workbench/chart-indicators.json` 独立原子保存；坏文件保留并提示，原工作区布局格式不变。关闭确认后先停止新计算，再保存及退出；恢复设置不会自动运行策略。

离线验收包括官方公式对照、VP 小样本与小数档位、版本隔离、固定区间编辑、断线恢复、设置重开、多格多指标持续显示和退出；使用合成行情及临时配置，不覆盖用户文件。账户开盘实时行情仍需本机验收；本功能不代表策略验证或模拟/实盘交易通过。
