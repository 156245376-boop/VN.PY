# 天勤现成功能与本机入口

本机登录窗口、启动/停止按钮和实验摘要由本项目提供；浏览器中的行情图、账户展示、
策略绘图与回测报告页面使用天勤 SDK 原生资源。官方说明见
[策略程序图形化界面](https://doc.shinnytech.com/tqsdk/latest/usage/web_gui.html)。

## 查看与使用

双击 `启动天勤.vbs`，选择 **天勤现成功能**。无需填写账号即可查看：

- 功能目录：组件是否已安装、当前项目是否已接入、权限和限制、官方文档链接。
- 官方示例源码：按名称搜索本地原版示例，在只读窗口阅读；不会运行其中的代码。
- 技能与资源：安装位置、版本、资源数量和检查问题。

当前固定 TqSdk 3.10.2，原版包内有 86 个示例、70 个技术指标函数、41 个序列计算函数、
45 个网页资源文件。组件均使用已安装的 SDK，不向项目源码复制整套上游代码。
官方技能包的 14 个文件已安装在 Codex 技能目录，已与官网下载包逐字节核对一致；
技能是接口使用说明与定位地图，示例和网页来自 SDK 安装包。

| TargetPosTask 与下单任务 | 原生库已安装；当前执行使用已有薄适配及保护 |
| TargetPosScheduler、TWAP 与时间表 | 原生库已安装，按需接入；直接 Twap 不支持回测 |
| TqScenario | 原生库已安装；仅期货、单账户、同步快照试算 |
| TqNotify、TqChan 与异步任务 | 原生库已安装；通知收集不等于短信或邮件推送 |

官方示例的唯一额外第三方库 `scikit-learn==1.9.1` 已通过锁定的 `official-examples`
依赖组补齐；安装依赖不表示启用机器学习研究。示例可能使用旧合约、占位凭证、
其他交易规则或专业功能，不作为可直接投用的策略；当前实验和保护逻辑保持原样。

**安装组件不能开通服务。** 专业版下载、部分数据、股票模拟、本地风控、企业直连等，
仍受各自权限约束；多账户也不能笼统视为专业专属。详见
[专业版说明](https://doc.shinnytech.com/tqsdk/latest/profession.html)与
[企业服务](https://doc.shinnytech.com/tqsdk/latest/enterprise.html)。
[快期专业版](https://www.shinnytech.com/products/qpro)是另一个 PC 客户端，
不是技能包附带的 Python 模块，本轮未购买、开通或安装该付费客户端。

## 安装与核对

日常仍使用 `tools/setup.ps1` 和 `tools/check.ps1`。
本次增加明确的 `setup.ps1 -UpdateLock` 开关，用于已决定的依赖变更；
只重新解析依赖，不传 `--upgrade`，保留兼容的原锁定版本。默认安装仍要求锁文件一致。

完整检查除现有测试外，还会导入现成组件，按 wheel RECORD 哈希逐个验证 demo/web 资源，
核对技能文件和示例依赖。检查不创建 API 会话、不下载行情，也不运行示例。
如需机器可读清单，可执行：

```powershell
.\.venv-tqsdk\Scripts\python.exe -I -B tools\native_inventory.py
```

网页或示例损坏时，先结束运行并关闭工作台，再执行 `tools/setup.ps1 -RepairSdk`，
按锁文件重新安装同一版本 SDK；普通同步不会主动修复已安装包中的文件。
全新电脑还需安装
[官方技能包](https://doc.shinnytech.com/tqsdk/latest/ai_editor/skills/tqsdk-trading-and-data.zip)。
最新文档可能对应更新版本，接口判断始终优先本机固定版本，不自动升级 SDK。

本轮本机验收：`tools/check.ps1` 通过，85 项测试、Ruff、依赖一致性与封存检查通过；
135 个 demo/web 文件符合 wheel RECORD，19 类组件可导入，技能 14 文件可读。
已确认只新增示例所需的 5 个包，所有原锁定包版本不变。
窗口浏览测试按实际启动方式使用独立进程，未登录账户、运行示例或验证交易策略。
