# 架构决策记录索引

## 本目录的规则

- **只追加,不修改。** 决策变更时新增一条记录,并把被取代的那条标注为「已取代,见 ADR-XXXX」。不编辑历史记录的内容 —— 目的是让设计的演化过程可见,而非只保留当前快照。
- **承重性标注**是本索引最重要的一列。审阅者据此判断哪些决策改动会产生连锁影响、哪些只是局部选择。
  - **承重** —— 改动会波及多个 Module_Package,或使既有产物需重新评估
  - **局部** —— 改动影响范围限于单个 Module_Package
- 每条记录的固定小节:背景、决策、理由、放弃的方案、后果、相关。其中**「放弃的方案」是给未来审阅者最关键的一节** —— 它防止重新提出已被否决过的方案。
- 记录中引用需求编号时使用 `R<编号>.<条目>` 形式,引用其他决策时使用 `ADR-XXXX` 形式。校验脚本(R26.7)会检查引用不指向不存在的目标。
